Use your own image

Choose a PNG, JPEG or WebP. It will fit the panel with black borders, without cropping. Animated files use their first frame.

Add a display

Update to local-display firmware 2.0.14 or newer first. Restart the panel, then connect within two minutes. Both devices must be on the same local subnet.

Find the address in your router's device list. Reserve it there so it stays the same. Reconnecting updates the saved address.

Use in HA automations

Install the companion actions, restart Home Assistant, then add Pixora LED (Local) in Settings → Devices & services. Connect each panel by its IP address after restarting it.

Each panel appears as a local notify entity in HA. Use Send a notification message and select the display. For color, duration or images, choose Pixora LED (Local): Show card or Show image card in an automation. Select the display, content and duration. The installer only updates Pixora's own integration folder and backs up any previous copy.

Update panel firmware

Select the display above, then choose its S3 user-OTA .bin file. Both S3 panel sizes use the same image. Keep the panel powered on until it restarts.

Add a display

Name it, choose your panels, and connect it to your 2.4 GHz Wi-Fi.

Make it yours

Adafruit MatrixPortal S3 controller. Both sizes use the same firmware. Tidbyt requires different firmware and is not supported by this installer.

Wi-Fi

Wi-Fi settings stay in this HA app’s private storage so another display can use them. Passwords are never returned to this page.

How do you want to install it?

Connect the MatrixPortal S3 to Home Assistant with a USB data cable. For a VM, pass the USB device through to HA.

The file includes this display’s Wi-Fi settings and private pairing key. Keep it private. Flash at address 0x0 with ESPHome Web or esptool, then delete your downloaded copy.

Setup saved. Select this profile above when you are ready to install.

Open ESPHome Web Connect → Install → choose the downloaded .bin file. Then return here.

Finish connecting

Once the display joins Wi-Fi, enter its IP address from your router. This verifies the saved profile key and adds the display to Studio and Home Assistant.
